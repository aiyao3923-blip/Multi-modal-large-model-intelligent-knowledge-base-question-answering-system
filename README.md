# 论文知识库 · 阅读与问答

为阅读论文设计的本地 RAG 工作区：创建自己的知识库、上传论文、提出问题、对照原文理解回答。不再提供行业模板或自动生成示范资料。

> 当前实施与未完成验收见 [PROGRESS.md](PROGRESS.md)，总体方案见 [计划书.md](计划书.md)。在线模型未实际验收时，不将离线检索或测试桩计为真实生成能力。

## 开始使用

在项目根运行：

```powershell
.\检查本机.cmd
.\启动本机.cmd
```

打开 <http://127.0.0.1:5173>，使用已有账号登录。不要为解决登录问题重复初始化数据库。

1. **知识库 → 新建论文库**：填写名称即可，默认私人，只有所有者可维护。
2. **上传论文**：支持文本层 PDF、Word、Markdown/文本、表格等。上传完成与解析成功不同；显示“已入库”且有片段后才能可靠检索。
3. **进入问答**：工作区只使用当前库的资料与会话，切换知识库会开启新对话，不沿用别库历史。
4. **阅读回答**：点击正文中的 `[1]` 或来源卡查看片段，再切“论文原文”查看 PDF 的对应页。
5. **调整空间**：拖动两侧分隔条；聚焦分隔条后用左右键微调、Shift 加速、Home/End 调至边界。“专注阅读”隐藏侧栏，字号 A−/A+ 可调，“恢复默认布局”重置。窄屏使用可关闭抽屉。

## 回答到底来自哪里

| 显示状态 | 实际发生了什么 |
|---|---|
| 本地模型 / 模型回答 | 本次生成通道返回了正文和有效来源编号 |
| 生成未完成 / 仅检索证据 | 未配置模型、调用失败或来源编号无效；界面展示检索证据，不冒充生成答案 |
| 没有相关证据 | 当前知识库没有足够相关的可用片段，不凭模型常识补写论文事实 |
| 向量 + 关键词 / 向量检索 / 关键词检索 | 本次实际检索方式；详情可看命中数，不把相似度当置信概率 |

后端使用本地多语言 E5（显式配置时）和 BM25；证据重新绑定当前库、文档与版本，补足相邻同页内容后送给已配置生成通道。论文提示要求解释方法、比较研究并标注依据。有效引用编号并不自动证明答案准确，真实模型质量仍需独立问题评测。

没有 Embedding 时可进行关键词检索；没有生成模型时不能综合生成答案。扫描 PDF/图片需要额外本地 OCR，系统不会静默下载模型或伪称看懂图表。

## 隐私与数据边界

- 所有者拥有资料维护权；显式共享角色只读。系统管理员不因身份自动获得其他人的私库内容。
- 文档、片段、向量、缓存、会话、历史引用和原文件端点都核对库身份。权限或证据在生成过程中改变时，不保存过期回答。
- 上传原文件在 `backend/storage/uploads`，业务数据库在 `backend/storage/data`；这些目录不进入 AOCI。
- 原文浏览通过带鉴权的 Blob，不把 token 放进 URL。PDF 文件头核验后才允许嵌入；HTML/SVG 不在阅读器执行。浏览器吞掉空的二进制响应时，仅同鉴权端点进行有界编码传输兜底。
- **在线模型问答会将问题和选中证据发送到当前配置端点，并可能计费。** 本地检索不调用在线生成。更换 provider/密钥/端点不属于普通测试。
- 删除旧演示数据必须先审查精确库 ID、业务行快照与保留清单；不会凭“空库”或名字自动删除用户创建的库。

## 工程结构

- `frontend/src/views/chat`：阅读工作区与问答流程。
- `frontend/src/components/ResizableWorkspace.vue`、`CitationReader.vue`：可调布局、授权证据阅读。
- `backend/app/services/qa_service.py`：同库检索、上下文、模型生成与引用事务。
- `backend/app/services/kb_service.py`：所有权、共享、上传与文件边界。
- `backend/app/engines`：解析、切块、本地编码、关键词/向量索引、模型网关。
- `backend/tests`、`frontend/tests`：隔离行为、权限与回归测试。
- `backend/scripts/retire_demo_libraries.py`：只读计划优先的精确旧数据退役工具，不默认执行删除。

历史版本治理仍保留兼容，未迁移库不会自动迁移。辅助统计、反馈和系统设置收纳为次级工具，不占论文阅读主路径。
